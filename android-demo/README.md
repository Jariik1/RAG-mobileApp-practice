# kvyik Android demo

Нативная Android-демонстрация интерфейса мобильного клиента kvyik. Приложение работает полностью офлайн: сначала показывает форму входа, а после успешной проверки — статичный экран корпоративного AI-ассистента в стиле макета с сайта проекта.

## Демо-доступ

- Логин: `admin`
- Пароль: `kvyik2026`

Данные намеренно заданы константами в `MainActivity.java`. Это прототип интерфейса, а не готовая схема авторизации для production.

## Возможности

- привычная форма входа с полями логина и скрытого пароля;
- проверка данных и сообщение об ошибке;
- переход к экрану чата после успешного входа;
- адаптивная нативная отрисовка тёмно-оранжевого интерфейса;
- анимированное боковое меню с выбором одного из трёх демонстрационных чатов;
- нижняя панель выбора модели `gemma-3`, `qwen2.5` или `llama-3.2`;
- панель настроек с анимированными переключателями истории и источников;
- визуальный отклик кнопок добавления и микрофона;
- анимированный индикатор поиска в базе знаний;
- отсутствие сетевых разрешений и внешних зависимостей приложения.

## Сборка

Требования: JDK 17+ и Android SDK Platform 37.0 с Build Tools 36.0.0.

```powershell
.\gradlew.bat assembleDebug
```

Готовая проверенная сборка также хранится в `apk/kvyik-demo.apk`.

## Структура

- `app/` — стандартный Android application module;
- `app/src/main/java/` — форма входа и нативная отрисовка чата;
- `app/src/main/res/` — тема, название и иконка приложения;
- `apk/` — готовый устанавливаемый APK.
